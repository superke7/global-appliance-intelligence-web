# 新闻标准标签（版本1.0）

本标准来自对Google Sheets《事件新闻总表》214条正式新闻的字段分布审计。规则只作用于用户确认的五个可公开新闻标签字段，绝不能把内部日志、审核意见、信息质量和内部经营判断导入公开网站。

## 结构和口径
- 事件阶段：规划拟议、谈判磋商、调查审查、诉讼裁决、已宣布待实施、推进中、已生效/投产、暂停延期、结束撤销、数据/结果发布。
- 国家/地区：拆为多个已有地理实体，**欧盟与欧洲不同**，德国等欧盟成员不自动额外添加欧盟；仅合并确认属于同一实体的别名，如“印尼”→“印度尼西亚”。
- 新闻标注：新事件、事件进展、独立资讯、历史补录、历史收录；“竞品动态”作为事实类型从分类和原字段体现，不再制造额外主标签。
- 影响程度：高、中高、中、低。带有条件的原始描述完整保留（例如“高（命中附件税号）；其他待核验”），筛选归入其开头主等级。影响程度指公开行业关注度，不表示内部风险优先级。
- 事件分类：贸易与政策、制造与产能、市场与渠道、投资与合作、监管与供应链。

**双层显示规则**：网站文章详情保留Sheet原字段完整描述；筛选控件只用标准标签。阶段的具体协商/生效条件、分类里的政策工具关键词，不应直接当作筛选项。未知/有争议值必须标待复核，不能按国家或常见词强行推断。历史数据应通过已公开文章的稳定ID或唯一来源URL进行匹配，65条历史迁移编号不可由日期序号猜测。

## 发布前安全闸门
- 页面代码及标签程序只接收上述五个公开字段，不得读取额外的Sheets内部列作公开标签。
- 先在非公开环境将Sheet经过审核的值映射到对应的**已公开**新闻。无唯一匹配不发布该条元数据。
- 新闻标题、正文、背景补充必须继续与正式Sheet一致；原始字段及规范标签不是两份相互独立的人工数据库。
- 任何未经过安全审核的标签、数据行、内部分析不允许先上传到公开GitHub PR/Issue/分支用于CI测试。
- 不直接改变Google Sheets既有19列和已经审核的原字段，只在公开新闻JSON或安全映射中增加派生标签。

## 当前进度
- 已审计214条正式新闻：原始阶段210种、国家地区118种组合、标注26种、影响程度5种、分类177种。
- 建立可读的显式阶段例外映射和通用规则，制定保留原文的五项标准化输出。
- 当前PR只提供字典、可复用归类程序与单元测试，不发布含待审核新闻的原始数据，也不修改网站新闻或定时任务。
