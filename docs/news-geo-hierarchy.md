# 地区筛选的上级关联规则（2026-10-17）

网站的「国家/地区」是**新闻涉及范围筛选**，不等于政策制定机构或政策管辖权判断；用户选择「欧盟」时，可命中以法国、德国等欧盟成员国为涉及地区的新闻，**不能据此声称法国国内新闻由欧盟发布**。

## 两层数据，方向不可反转

- 原始标签：直接保留Google Sheets「国家/地区」原文与明确出现的实体（`publishing/news_taxonomy.py::geo_tags`）。绝不修改原始Sheet，也不回填推断出的区域。
- 筛选扩展：根据 `config/news-geo-hierarchy.json` 的2026-10-17成员关系与地区层级，计算 `expand_geo_filter_tags`；只在编译静态网站的 `news.html` 时生成用于匹配的 `data-geos`，不增加公开批次原始标签字段。
- 国家 → 所属区域／组织 → 其上级区域，**单向**传播。例如法国→欧盟→欧洲，但「欧洲」不意味着欧盟，也不意味着所有欧洲国家。
- 同一篇新闻涉及多个国家时，任意国家或其上级区域均可命中；不同筛选维度仍采用 AND 组合。
- 未审核历史文章保持可浏览，但不能凭标题推断国家标签。

## 关键边界案例

| 文章明确涉及 | 筛选可命中 | 不自动匹配 |
|---|---|---|
| 法国、德国 | 法国/德国、欧盟、欧洲 | 不产生所有27国标签 |
| 英国、挪威 | 英国/挪威、欧洲（挪威还属于北欧） | 欧盟 |
| 越南 | 越南、东盟、东南亚、亚洲 | 欧盟 |
| 墨西哥 | 墨西哥、北美、拉美 | 南美 |
| 巴西 | 巴西、南美、拉美 | 北美 |
| 土耳其 | 土耳其、欧洲、亚洲 | 欧盟 |
| 澳大利亚 | 澳大利亚、大洋洲 | 东盟 |

欧盟27国名单参照 <https://european-union.europa.eu/principles-countries-history/eu-countries_en>；东盟在2025年10月26日纳入东帝汶成为11个成员，参照 <https://asean.org/forging-a-new-era-timor-leste-admitted-into-asean/>。

**注意历史时态：** 本表是2026-10-17成员资格快照，适用本站当前2026年新闻归档。如果将来纳入2020年以前的英国新闻、欧盟/东盟更早的成员变动，必须引入按事件日期判断的历史成员关系，不能用今天的资格反向套用。

## 验收
`python3 -m publishing.test_news_taxonomy`：核对国家→组织/区域单向逻辑。
`python3 scripts/build-pages.py && python3 -m publishing.test_news_browser`：验证真实网页HTML中法国文章可筛欧盟、英国文章不属于欧盟、越南文章可筛东盟、墨西哥可筛北美/拉美。

本变更不修改RSS、网站新闻正文、Event、Google Sheets或早报定时任务。未来更正成员资格只需改维护者审定的分层规则，并由现有Pages工作流重建筛选页。
