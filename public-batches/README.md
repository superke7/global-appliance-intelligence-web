# 最终公开JSON批次

本目录保存已经公开化处理并通过标准合同校验的公开JSON，是GitHub Pages网站与RSS的公开数据源。

固定路径：

```text
public-batches/YYYYMMDD/public-batch.json
```

规则：

- 每个北京时间日期最多一个文件；
- 公开站按“实际入站日”归批：今天首次进入公开站的新闻进入今天的批次，原新闻日期保留在 `source_published_date`；
- 当天批次允许只追加新item，不允许删除、改写或重排已经公开的旧item；
- 昨天及更早日期的批次保持不可变；
- 定时早报已收录但此前未入站的新闻，以及人工提示GPT额外补录并完成核验的新闻，都进入实际补录当天的公开批次；
- 同一 public_id 或同一已公开原文URL不得重复入站；
- 文件不得包含海尔内部信息、内部字段、内部风险评级、内部负责人或“对海尔全球布局的启示”；
- 公开仓库只能接收经过私有主仓库校验后的公开批次，不保存Secrets、服务器配置或内部数据；
- 当天文件create或append update都会触发GitHub Pages，同一次构建同时更新网站页面和RSS。

因此，网站与RSS始终以当前最新公开批次保持同步；当天后续补录成功后，补录新闻会同时出现在当天网站和当天RSS中。
